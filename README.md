# MappleAppQ

Aplikasi Android (WebView) untuk https://mapple.rip

## Build APK lewat GitHub Actions
1. Push repo ini ke GitHub.
2. Buka tab **Actions** → workflow **Build APK** (jalan otomatis setiap push, atau klik **Run workflow**).
3. Setelah selesai, buka run tersebut dan unduh **mapple-debug-apk** di bagian *Artifacts*.
4. Ekstrak zip-nya, lalu install `app-debug.apk` di HP.

## Build lokal
Buka folder ini di Android Studio, lalu **Build → Build APK(s)**.
